# 2026-11-21: Project started — KeyChan

Created Forge project (T3). Created GitHub repo. Selected components:
- GoodDisplay 1.54" color SPI e-paper (GDEY0154D67)
- ESP32-C3 SuperMini
- 50mAh 3.7V LiPo + TP4056 USB-C charging
- 2× tactile switches (SMD)
- Custom 2-layer PCB (KiCad) + 3D-printed snap-fit case (Fusion 360)
